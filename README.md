# Miqas Al Bahrain website

Static, GitHub Pages-ready website.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `miqas-albahrain`.
2. Upload all files/folders from this package to the repository root.
3. In GitHub: Settings → Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public website URL.
